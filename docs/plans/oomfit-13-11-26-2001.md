# 🗺️ Final Implementation Plan: oomfit Directory Modernization & User Identity (Batch 1)

## 📋 Executive Summary
This implementation plan executes a three-stage progressive enhancement for **oomfit**: establishing a dedicated account creation workflow with a global navbar badge, modernizing the home directory layout by replacing static preset commands with an interactive board hover preview hero, and implementing a centered minimalist typewriter search with dynamic board link highlighting. 

To eliminate merge conflicts across shared components (`src/app/page.tsx`), this plan follows **Strategy 1 (Safe Sequential Pipeline)**. Each task is executed on an isolated branch, validated against `npm run build`, submitted as a standalone pull request, and verified before the subsequent branch begins.

## 🤖 Worker Delegation Manifest

### Worker 1: `worker-signup-ui`
- **Assigned Task:** Issue #1 — Account Creation UI & Global Navbar Profile Badge
- **Base Branch:** `main`
- **Working Branch:** `issue-1-account-creation-ui`
- **Workspace Isolation:** `branch` (isolated clone)
- **Target Files:**
  - `src/app/signup/page.tsx` (New route)
  - `src/app/page.tsx`, `src/app/catalog/page.tsx`, `src/app/thread/[id]/page.tsx` (Navbar profile badge addition)
  - `src/lib/user.ts` (Client-side localStorage mock profile persistence)
- **Done When:**
  - `/signup` form allows input of username, handle, bio, and avatar color/initials with client storage persistence.
  - Profile badge renders on the far left of the top navigation bar across all main views, linking to `/signup`.
  - Automated check passes: `npm run build`
  - Submits PR with title `[TASK]: Account Creation UI & Global Navbar Profile Badge` closing Issue #1.
- **Circuit Breaker:** Max 3 build attempts before pausing.

### Worker 2: `worker-home-hero`
- **Assigned Task:** Issue #2 — Home Directory Simplification & Interactive Board Hover Hero
- **Base Branch:** `main` (after Issue #1 is merged)
- **Working Branch:** `issue-2-home-board-hover-hero`
- **Workspace Isolation:** `branch`
- **Target Files:**
  - `src/app/page.tsx`
- **Done When:**
  - Bottom `[DEV GUIDE] PRESET COMMANDS` box and buttons are completely removed.
  - Top horizontal preset pills row and subheader descriptions are removed; directory permanently defaults to primary board categories.
  - Interactive "Board Preview Hero" card component renders below directory grid, dynamically updating title, description, placeholder art, and "Enter Board" button on board link hover.
  - Automated check passes: `npm run build`
  - Submits PR closing Issue #2.
- **Circuit Breaker:** Max 3 build attempts before pausing.

### Worker 3: `worker-search-anim`
- **Assigned Task:** Issue #3 — Minimalist Centered Typewriter Search Bar with Board Highlighting
- **Base Branch:** `main` (after Issue #2 is merged)
- **Working Branch:** `issue-3-typewriter-search-highlight`
- **Workspace Isolation:** `branch`
- **Target Files:**
  - `src/app/page.tsx`
- **Done When:**
  - Search input is centered, minimalist (no heavy bounding box), and features a flashing text cursor.
  - Automated typewriter animation cycles through sample keywords (e.g. "anime", "gaming", "tech") with typing, pause, and backspacing.
  - User click/focus immediately halts the animation and clears input for manual typing.
  - Matching boards remain brightly visible while non-matching boards dim in opacity during query matches.
  - Automated check passes: `npm run build`
  - Submits PR closing Issue #3.
- **Circuit Breaker:** Max 3 build attempts before pausing.
