# 🗺️ Final Implementation Plan: oomfit Directory Modernization & User Identity (Batch 1)

## 📋 Executive Summary
This implementation plan executes a three-stage progressive enhancement for **oomfit**: establishing a dedicated account creation workflow with a global navbar badge, modernizing the home directory layout by replacing static preset commands with an interactive board hover preview hero, and implementing a centered minimalist typewriter search with dynamic board link highlighting. 

**Execution Mode: Unattended Autonomous Pipeline (Overnight Mode)**  
The Lead Agent acts as an autonomous coordinator. Human checkpoints between steps are completely eliminated. The coordinator dispatches workers sequentially, verifies each branch via `npm run build`, automatically merges verified branches into `main`, and advances to the next worker. The human only performs a single, 5-minute UI signoff in the morning.

## 🛡️ Autonomous Failsafe & Circuit Breaker Protocol
If any failure occurs during execution or merging, the agent must adhere to this protocol:
1. **Worker Build Failure:** Max 3 consecutive `npm run build` attempts. If the 3rd attempt fails, stop the worker, leave a comment on the GitHub issue detailing the compile errors, and halt the pipeline.
2. **Merge Failure / Conflict:** If `git merge` encounters a conflict or post-merge `npm run build` fails on `main`:
   - Run `git merge --abort` immediately to guarantee `main` remains pristine.
   - Preserve the worker branch untouched.
   - Run `gh issue comment [Issue #] --body "⚠️ Automated Merge Paused: Conflict or build regression detected. Aborted merge to protect main. Branch preserved for review."`
   - Halt pipeline cleanly.
