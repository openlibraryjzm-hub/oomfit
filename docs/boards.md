# oomfit Boards Catalog & Reference (`boards.md`)

This document serves as the master brainstorm directory of board titles for **oomfit**. It combines broad universal evergreen anchors with obsessive, high-affinity niches to stress-test the dynamic search, tag-clustering, and fuzzy/semantic preset engines.

All boards currently route to the unified placeholder catalog (`/catalog?b=[shortcode]`).
